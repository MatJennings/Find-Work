# Approved Application Answers

Record only complete substantive answer sets the user explicitly approves or asks to preserve. Keep each target application's exact set in its own approved-wording snapshot.

For each entry, preserve:

- Approval date
- Company and role context
- Exact question and approved answer
- Competencies and reusable examples demonstrated
- Evidence and confidentiality limits
- Future adaptation guidance

## Standing form-answer defaults

Optional. Record only defaults the user explicitly confirms, with the date, for routine questions such as start date or availability, how the user heard about the role, text-message consent, or whether the user knows someone at the employer. Leave a question blank until confirmed. A default answers only the question it names. It never establishes citizenship, clearance, licensure, documents, relationships or agreement to new terms. Sensitive voluntary answers belong here only if the user asks, and never in employer-facing prose or logs.
