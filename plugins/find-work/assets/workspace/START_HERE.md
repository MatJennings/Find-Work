# Start Here

This folder is your private job-search workspace. A folder inside OneDrive, iCloud, Dropbox, or a similar service is cloud-synced. Choose a device-local location if you do not want that synchronization.

1. Open this folder in the ChatGPT desktop app.
2. Ask Codex: `Use $setup-job-search to finish setting up this workspace.`
3. Add previous resumes, LinkedIn exports, portfolios, reviews, certificates, or other useful records to `sources/imported/` when invited. Tell Codex when the uploads are finished, or explicitly choose to continue without prior materials.
4. Work through the career-foundation conversation. Codex will address one employer or substantial engagement at a time.
5. Review and approve the resulting chronology, evidence ledger, target profile, and writing preferences.
6. Use `$find-jobs`, `$review-job`, `$draft-application`, and `$produce-files` as needed.

The workspace ends its application workflow at `Files produced`. It does not track external submission states.

Keep this folder private. Do not publish it or add a Git remote unless you have reviewed its contents and intentionally chosen to do so.
