# Review Job

1. Read `AGENTS.md`, the approved profile and evidence files, current trackers, and any existing application record.
2. Resolve the exact role. Verify live-board presence and a functional application path on the official employer site. If either cannot be inspected, mark the role `uncertain` and state what the user must verify manually.
3. Record the role's responsibilities, required qualifications, preferred qualifications, terminology, compensation, location, work arrangement, and travel.
4. Research the company from authoritative sources. Record its business, customers, mission, headquarters, approximate size, ownership, stability signals, and material ethical concerns.
5. Build a match map with separate columns or sections for direct evidence, transferable evidence, gaps, and prohibited claims. Cite `experience/evidence_ledger.csv` and employer context files.
6. Recommend `Apply`, `Research further`, `Maybe`, or `Reject`, explaining the decisive tradeoffs rather than relying on an unexplained score.
7. Update `job_search/roles.csv`, `job_search/reviewed_roles.md`, and `job_search/search_log.md`.
8. Create or update `applications/in_progress/<company-role>/application_record.md` and `role_review.md` using `../../assets/templates/application_record.md` and `../../assets/templates/role_review.md`.
9. Continue with `$draft-application` only when the user asks for application wording.

Do not create DOCX or PDF files. Do not use uncertain, confidential, or unsupported claims as qualifications.
