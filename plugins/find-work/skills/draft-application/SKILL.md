# Draft Application

1. Read `AGENTS.md`, the verified role review, candidate profile, chronology, evidence ledger, relevant employer context, and writing preferences.
2. If the role or match map is missing or stale, perform the applicable `$review-job` steps first.
3. Draft one complete reviewable Markdown document in chat. Include the concise role recommendation, match map, every proposed resume section and bullet, the complete cover letter when requested, application answers, and intentionally excluded claims.
4. Use only supported facts. Preserve the difference between direct evidence and transferable evidence. Never upgrade a claim's evidence level for rhetorical strength.
5. Follow the candidate's preferred tone, length, punctuation, formatting, and document structure. Use employer terminology naturally without keyword dumping.
6. Revise in chat until the current complete wording is unambiguous. Do not save a working file unless the user requests a snapshot or a handoff requires it.
7. When the user approves the complete wording or unambiguously requests final files, save the exact approved wording as `approved_application_wording.md` in the application folder and continue with `$produce-files`.

Do not create, export, or save DOCX or PDF files in this workflow. Approval of one section does not imply approval of the complete application.
