# Live desktop setup and feedback

Use this during ordinary setup with a real user. There is no scripted full-workflow trial to run. The maintainer runs targeted tests separately. Actual Free-account completion, usage savings, writing quality and revision effort remain untested until observed live.

## Before setup

- Update or clone the latest repository. Install the plugin, or refresh an existing installation, using the documented platform command. Start a new task after refresh.
- Open a separate private local folder. Explain cloud synchronization only when it affects the user's choice. Never put candidate sources into the distributable repository.
- Record the actual account plan, app surface, plugin version, workspace schema and available tools in the private capability record. Do not assume that Free means a particular model, browsing capability or fixed allowance. Plan features can change.
- Confirm that older local skills are not shadowing the shared plugin. Existing workspace instructions are preserved by migration. Review any policy that conflicts with shared updates, especially official-only verification or candidate-specific writing rules.

## Observe during normal use

| Work the user actually does | What to check |
|---|---|
| Setup | Correct private folder, accurate capability record, no forced paid tools, clear next step |
| Source intake | Waits for upload completion, preserves originals, reports unreadable sources |
| Foundation | Reconciles dates and scope, separates factual support from disclosure, asks useful questions without unnecessary repetition |
| Search, if requested | Bounded requested coverage, verified new findings, correct reuse of known openings, explicit access limitations |
| Review, if requested | Exact role identity, relevant evidence, unknown versus confirmed gaps, clear tradeoffs |
| Draft and revision, if requested | Complete requested wording, supported claims, candidate voice, useful changes, no foreign-company contamination |
| Production, if requested after approval | Exact approved wording, available tooling only, honest validation limitations, Ready to apply rather than Applied |
| Later resumption | Recovers matching records and outstanding work without repeating completed steps |

There is no need to complete every phase today. Mark untouched phases not observed, never passed. If tools or account limits interrupt work, preserve exact approved state and a concise next action in the private application record. Do not infer failed capabilities from account tier alone.

## Record actionable feedback

Keep real candidate wording, identities, records and screenshots in the private workspace. Public reports should contain a redacted reproduction or clearly synthetic example.

For each issue, record:

- Date, app surface, actual plan, plugin version and phase
- Short request and the expected behavior
- Actual behavior, including repeated reads, avoidable questions or missing evidence
- Available capabilities and any explicit limit or error message
- Recovery or revision effort and whether the task completed
- Whether the problem belongs to shared workflow, private preferences, missing evidence, tooling or account availability
- The smallest repeatable example without personal or confidential information

Report observable usage only when the app exposes it. Account-wide usage changes are not attributable to a task when other activity overlaps. Source bytes, tool calls and elapsed time are useful separate observations, not billed token savings. Do not promise a number of applications per Free allowance.

## Revise after the session

Prioritize failed truthfulness, confidentiality, approval, role identity or submission state first. Next address blockers, wasted turns and repeated work. Add a targeted test for reproducible helper or workflow defects. Adjust shared behavior only when generic, and leave personal writing preferences in the user's private profile. Defer optional features until a concrete problem justifies them.

Official OpenAI guidance recommends limiting unnecessary context, sources and output. It does not establish this plugin's actual Free-account results. See [usage guidance](https://learn.chatgpt.com/docs/pricing). Guidance checked 2026-10-02.
